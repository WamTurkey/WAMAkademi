# WAM Akademi

Moodle local plugin: `local_wamakademi`

## Install

1. Copy repository contents (except `extras/` and `README.md`) into:

```text
moodle/public/local/wamakademi
```

2. Optionally copy logo assets:

```text
extras/wam-assets → moodle/public/wam-assets
```

3. Visit Site administration → Notifications to install/upgrade.
